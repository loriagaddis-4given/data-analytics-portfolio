# Healthcare Data Analytics Portfolio

I am a healthcare data analyst with more than 20 years of experience working with hospital data, corporate analytics, and HL7 interfaces. This portfolio highlights projects that use SQL, data validation, and Tableau to examine healthcare reimbursement and market questions.

## Portfolio Projects

### Market Feasibility for a Proposed Rural Imaging Center

Analyzed imaging utilization and billed charges from a target rural ZIP code to assess potential demand for a proposed outpatient imaging center. The analysis also identified women over age 40 with no mammography record in the available data as a potential outreach population.

**Tools:** Excel, DuckDB SQL, Jupyter Notebook, Tableau  
**Data:** Synthetic relational healthcare data

- [View the GitHub project](https://github.com/loriagaddis-4given/Imaging_Center_Viability)
- [View the interactive Tableau dashboard](https://public.tableau.com/app/profile/lori.gaddis/viz/ImagingCenterViability/Dashboard1)

### Lab Contract Reimbursement Analysis: Percent of Charges vs. Fee Schedule

Compared modeled allowed amounts under a hospital’s current percent-of-charges methodology with a proposed CPT-based fee schedule. The analysis validated four related datasets, accounted for charge reversals, and identified the laboratory tests producing the largest modeled reimbursement differences.

**Tools:** DuckDB SQL, Jupyter Notebook, Markdown, Tableau  
**Data:** Synthetic outpatient laboratory data

- [View the GitHub project](https://github.com/loriagaddis-4given/OP_Lab_Contract_Analysis)
- [View the interactive Tableau dashboard](https://public.tableau.com/views/OPLabContractImpact/OPLabContractAnalysis)
